# Screenshot Evidence

This folder contains the evidence screenshots for the Cisco Packet Tracer project.

Use these exact filenames so the image links in the root `README.md` work:

- `01-topology.png` — full network topology.
- `02-vlans.png` — VLAN verification.
- `03-trunks.png` — trunk verification.
- `04-router.png` — router subinterfaces.
- `05-dhcp.png` — DHCP configuration or client addressing.
- `06-web-dns.png` — DNS and HTTP server settings.
- `07-ping.png` — successful ping/name-resolution/browser test.
- `08-port-security.png` — port-security verification, only if configured.

If you rename or upload screenshots, keep the filenames above in sync with the links in the root `README.md`.
