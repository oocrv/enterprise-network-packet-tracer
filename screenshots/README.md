# Screenshot Evidence

Upload your screenshots to this folder using the following filenames:

- `01-topology.png` — full network topology.
- `02-vlans.png` — VLAN verification.
- `03-trunks.png` — trunk verification.
- `04-router.png` — router subinterfaces.
- `05-dhcp.png` — DHCP configuration or client addressing.
- `06-web-dns.png` — DNS and HTTP server settings.
- `07-ping.png` — successful ping/name-resolution/browser test.
- `08-port-security.png` — port security, only if configured.

After uploading, edit `README.md` and replace each `ADD SCREENSHOT` comment with the corresponding Markdown image link. Example:

```markdown
![Complete network topology](screenshots/01-topology.png)
```
