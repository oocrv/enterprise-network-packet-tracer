# Screenshot Evidence

Upload your screenshots to this folder using the following filenames:

- `01-topology.png.png` — full network topology.
- `02-vlans.png.png` — VLAN verification.
- `03-trunks.png.png` — trunk verification.
- `04-router.png.png` — router subinterfaces.
- `05-dhcp.png.png` — DHCP configuration or client addressing.
- `06-web-dns.png.png` — DNS and HTTP server settings.
- `07-ping.png.png` — successful ping/name-resolution/browser test.
- `08-port-security.png.png` — port security, only if configured.

The screenshots are already uploaded. The main `README.md` links to them using their current filenames. For future uploads, prefer a single `.png` extension. Example link:

```markdown
![Complete network topology](screenshots/01-topology.png)
```
